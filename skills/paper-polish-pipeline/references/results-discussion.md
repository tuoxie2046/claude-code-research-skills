# Stage 4 · results-discussion / 结果与讨论深化

> 用于结果只会写"由图可知""可以看出",或讨论只是重复结果、缺少分析深度时。
> Use when results merely say "as the figure shows" and the discussion just restates them.

## 任务 / Task
提升结果分析的逻辑性与讨论深度,从"描述结果"走到"解释结果"。这不是语言润色。遵守全局铁律。
Raise the logic of the analysis and the depth of the discussion — move from describing
results to explaining them. This is not language polishing. Follow the IRON RULES.

## 优化逻辑 / Reasoning chain
1. 准确描述结果 — state the results accurately
2. 提炼趋势、差异或规律 — extract trends, differences, patterns
3. 分析可能原因 — discuss plausible causes
4. 说明结果与研究问题的关系 — link results back to the question
5. 适当讨论结果的意义 — discuss significance, in measured terms
6. 必要时补充局限性 — note limitations where needed

## 本阶段附加约束 / Stage-specific constraints
- 不改变任何数据或实验结果,不新增原文没有的图表信息。Change no data or results; add no figure
  or table content that the source lacks.
- 不把"可能原因"写成"确定机制",不把相关性写成因果性,不把有限样本的结论写成普遍规律。
  Keep "possible cause" from becoming "established mechanism", correlation from becoming
  causation, and a limited-sample finding from becoming a universal law.
- 避免"效果很好""具有重要意义"这类空泛表达。Avoid empty phrasing like "works well" or "is
  highly significant".

## 输出格式 / Output
1. **原文问题 / Problems** — 结果分析与讨论的主要不足。
2. **优化思路 / Approach** — 如何从"描述结果"提升到"解释结果"。
3. **修改后文本 / Revised text** — 一版更有分析深度的版本。
4. **风险提醒 / Risk note** — 哪些结论还需数据或文献进一步支撑。

## 输入 / Input
```
诊断结果、研究目标与方法(如有)/ Diagnosis, objective & methods (if any):【粘贴】
原文 / Source:【粘贴结果与讨论部分】
```
