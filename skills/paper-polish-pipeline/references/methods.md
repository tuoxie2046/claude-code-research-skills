# Stage 3 · methods / 研究方法规范化

> 用于方法描述不清、流程不完整或导师指出"方法不规范"时。
> Use when the methods are unclear or incomplete, or a reviewer calls them "not rigorous".

## 任务 / Task
让方法部分清楚、严谨、可复现,使方法能够回应研究问题。遵守全局铁律。
Make the methods clear, rigorous, and reproducible, and make them answer the research
question. Follow the IRON RULES.

## 检查与优化清单 / Checklist
- 研究对象、样本来源或数据来源是否交代清楚 — subjects / sample / data source
- 实验材料、设备、软件、平台或模型是否描述规范 — materials, equipment, software, model
- 变量、参数、控制条件与评价指标是否明确 — variables, parameters, controls, metrics
- 方法流程是否符合先后顺序 — procedure in correct order
- 方法选择是否能回应研究问题 — methods justified against the question
- 是否存在步骤跳跃、术语混乱或过于简略 — missing steps, inconsistent terms, too terse to reproduce

## 本阶段附加约束 / Stage-specific constraints
- 不添加原文没有的实验步骤,不改变原始研究方法。Add no steps the source lacks; do not change
  the original method.
- 设备、参数、样本量、软件版本、数据来源若原文缺失,一律标 `【此处需补充……】`,不得自填。
  If equipment, parameters, sample size, software version, or data source is missing, mark
  `[TO BE ADDED: …]` — never invent it.
- 不夸大方法先进性。Do not inflate how advanced the method is.

## 输出格式 / Output
1. **方法部分存在的问题 / Problems** — 哪里不清楚或不规范。
2. **需要补充的信息 / Missing information** — 作者还需补哪些内容(逐条)。
3. **规范化改写版本 / Standardized rewrite** — 正式学术论文写法。
4. **修改说明 / Notes** — 主要规范了哪些地方。
5. **待核查项 / To verify** — 被标注为待补充、需作者确认的项。

## 输入 / Input
```
诊断结果与研究目标(如有)/ Diagnosis & objective (if any):【粘贴】
原文 / Source:【粘贴研究方法部分】
```
