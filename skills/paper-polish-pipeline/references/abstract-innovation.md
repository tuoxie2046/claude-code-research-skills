# Stage 5 · abstract-innovation / 摘要与创新点提炼

> **顺序前提:** 必须在正文(第 2–4 阶段)改好之后再跑。摘要和创新点只能来自已定稿的正文,
> 提前写容易写空。**Precondition:** run only after the body (Stages 2–4) is revised — the
> abstract and contributions must come from the finalized body, not be written blind.

## 任务 / Task
基于已修改的正文,优化摘要与结论,并提炼创新点。不得新增正文中没有的信息。遵守全局铁律。
From the revised body, optimize the abstract and conclusion and distill the contributions.
Add nothing absent from the body. Follow the IRON RULES.

## 要完成的事 / Tasks
提炼研究背景、研究目的、研究方法、核心结果、研究结论,并提炼 3–5 条创新点。
Distill background, objective, method, key results, conclusion, and 3–5 contributions.

## 本阶段附加约束 / Stage-specific constraints
- 不新增正文没有的数据,不虚构实验结果,不夸大创新性。No new data, no invented results, no
  inflated novelty.
- 不使用"首次提出""填补空白""具有重大意义"等难以证明的表达。Avoid unprovable claims like
  "first to propose" or "fills a gap".
- 摘要与结论不要完全重复。The abstract and conclusion must not simply duplicate each other.
- 创新点必须具体,不能写成"方法新颖""视角独特"。每条尽量体现"针对什么问题 — 采用什么方法 —
  得到什么认识或改进"。Each contribution must be concrete and follow problem → method →
  gain, not vague labels like "novel method".

## 输出格式 / Output
1. **核心信息提取 / Core information** — 用表格整理:研究背景 / 目的 / 方法 / 核心结果 / 结论 / 贡献。
2. **优化后的摘要 / Abstract** — 一版 300–500 字的正式学术摘要。
3. **结论优化版 / Conclusion** — 克制、准确、有总结力。
4. **创新点 / Contributions** — 3–5 条,每条按"问题 — 方法 — 贡献"表达。
5. **关键词建议 / Keywords** — 3–6 个。
6. **待核查项 / To verify** — 任何依赖正文、需作者确认是否成立的提炼。

## 输入 / Input
```
已修改的正文 / Revised body:【粘贴修改后的主要内容,或 引言+方法+结果+结论(已定稿)】
```
