# Stage 2 · intro-litreview / 引言与文献综述重构

> 基于第 1 阶段的诊断结果来改,针对诊断指出的问题动手,不做泛泛润色。
> Build on the Stage 1 diagnosis; fix the problems it named rather than polishing in general.

## 任务 / Task
重构引言与文献综述,使其形成一条清晰的论证链。遵守全局铁律(尤其不虚构文献、不夸大、保真)。
Rebuild the introduction and literature review into one coherent line of argument. Follow the
IRON RULES (especially: no fabricated references, no overclaiming, preserve the source).

## 重构逻辑 / Target structure
按六段递进组织,每段只承担一个功能:
1. 研究背景 background — 这个问题为什么值得研究
2. 研究现状 prior work — 已有研究主要做了什么
3. 研究不足 gap — 现有研究还存在什么问题
4. 本文切入点 entry point — 本文从哪里进入这个问题
5. 研究目标 objective — 本文要解决什么问题
6. 研究贡献 contribution — 用克制、具体的语言说明价值

## 本阶段附加约束 / Stage-specific constraints
- 不新增原文没有的作者、年份或结论。Do not add authors, years, or findings absent from the source.
- 研究缺口要从已有文献自然推出,不能凭空断言"无人研究"。Derive the gap from the cited work; do
  not assert "no one has studied this" without support.
- 保留原文的研究对象、研究边界与核心观点。Keep the research object, scope, and core claims intact.

## 输出格式 / Output
1. **引言与文献综述的主要问题 / Main problems** — 简述原文为何需要改。
2. **优化后的段落结构 / Paragraph plan** — 逐段说明各段功能。
3. **修改后文本 / Revised text** — 一版完整、连贯、正式的学术化版本。
4. **修改说明 / Notes** — 主要解决了哪些问题。
5. **待核查项 / To verify** — 需要作者确认的引用、缺口判断或边界表述。

## 输入 / Input
```
诊断结果(如有)/ Diagnosis (if any):【粘贴第 1 阶段输出】
原文 / Source:【粘贴引言与文献综述】
```
